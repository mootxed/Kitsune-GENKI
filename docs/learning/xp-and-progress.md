# XP & Gamification — Система Опыта и Мотивации

Документ описывает систему начисления опыта (XP) и отслеживание активности (`src/xp-system.js`, `achievements.js`, `quests.js`).

---

## 💎 Правила начисления XP

| Действие                                  | Начисляемый XP | Ограничения и Защита                                                      |
| :---------------------------------------- | :------------- | :------------------------------------------------------------------------ |
| **Успешный FSRS Review (Good / Easy)**    | `+10 XP`       | Не начисляется при повторном ответе в Relearning очереди в той же сессии. |
| **Успешный FSRS Review (Hard)**           | `+5 XP`        | —                                                                         |
| **Новая карточка (New Item)**             | `+15 XP`       | Начисляется единоразово при первом изучении.                              |
| **Прохождение вспомогательной мини-игры** | `+10..20 XP`   | Начисляется при успешном доведении игры до конца.                         |
| **Выполнение дневного плана**             | `+50 XP`       | Зачисляется при 100% выполнении `dailySnapshot`.                          |

---

## 🔥 Стрик активности (Streak)

- Стрик увеличивается на +1 при активных занятиях в новый локальный учебный день.
- Если пользователь пропустил один локальный день, стрик сбрасывается до 0 (если в настройках не применен фриз стрика).
