# Staged Skill Opening — Поэтапное Разблокирование Навыков

В этом документе опиcана механика поэтапного открытия словарного запаса и навыков (`src/vocabulary-unlock-plan.js`).

---

## 💡 Концепция Staged Opening

Чтобы предотвратить перегрузку пользователя сотнями новых слов одновременно при старте новой главы Genki, приложение распределяет ввод новых слов главы по учебным дням:

- **День 1 главы**: Открывается первая порция слов (порции по 5-10 слов).
- **Последующие дни**: По мере выполнения ежедневной нормы повторений и освоения предыдущих слов, открываются следующие порции лексики.

---

## 🗝️ Поле `planLocked`

Каждая словарная позиция отслеживается в `state.vocabularyUnlocks[itemId]`:

```javascript
{
  unlockedDay: 2,      // Номер дня учебного плана, на котором элемент открыт
  planLocked: false,   // true - если элемент заблокирован до наступления соответствующего дня
  manuallyUnlocked: false
}
```

Карточки с `planLocked === true` фильтруются из всех учебных очередей и не предлагаются для изучения до наступления нужного дня.
