# Learning System Overview — Обзор Системы Обучения

Подсистема обучения **KotoKitsu** объединяет научно обоснованные алгоритмы запоминания, гибкий учебный план, систему мастерства и игровые механики мотивации.

---

## 🧩 Ключевые компоненты обучающей экосистемы

```text
                           ┌─────────────────────────┐
                           │   Genki Content Data    │
                           └────────────┬────────────┘
                                        │
                                        ▼
                           ┌─────────────────────────┐
                           │  Knowledge Items (KIs)  │
                           └────────────┬────────────┘
                                        │
                                        ▼
                           ┌─────────────────────────┐
                           │    Skill Cards Pool     │
                           └────────────┬────────────┘
                                        │
             ┌──────────────────────────┴──────────────────────────┐
             ▼                                                     ▼
┌─────────────────────────┐                               ┌─────────────────┐
│     FSRS Scheduler      │                               │ Mastery System  │
│ (Memory Retrievability) │                               │ (Skill Levels)  │
└────────────┬────────────┘                               └────────┬────────┘
             │                                                     │
             └──────────────────────────┬──────────────────────────┘
                                        │
                                        ▼
                           ┌─────────────────────────┐
                           │     SessionManager      │
                           │   (Queues & Review)     │
                           └─────────────────────────┘
```

1. **Knowledge Items (KIs)**: Атомарные единицы контента учебника Genki (слова, кандзи, грамматические конструкции).
2. **Skill Cards**: Карточки навыков, генерируемые из KIs (например, чтение кандзи, ввод значения слова, построение предложения с частицами).
3. **FSRS Engine**: Планировщик интервальных повторений `ts-fsrs`, рассчитывающий идеальный момент следующего показа карточки.
4. **Mastery System**: Независимая метрика многостороннего освоения предмета на практике (Level 0..4).
5. **SessionManager**: Оркестратор текущего учебного процесса, управляющий батчами, ошибочными попытками и отменой ходов (Undo).
