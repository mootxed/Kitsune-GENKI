# Mastery System — Система Оценки Мастерства

В этом документе описывается многокритериальная система уровня освоения навыков (Mastery) (`src/mastery.js`).

---

## 🎯 Разница между FSRS и Mastery

- **FSRS Due Date**: Отвечает на вопрос _"Когда карточку нужно показать пользователю, чтобы он её не забыл?"_.
- **Mastery Level**: Отвечает на вопрос _"Насколько уверенно и разносторонне пользователь владеет данным материалом на практике?"_.

---

## 🏆 Уровни мастерства (Mastery Levels 0..4)

```text
Level 0: Новый элемент (Не изучен)
   │
   ▼
Level 1: Знакомство (Пройдено 1+ повторение, Recognition)
   │
   ▼
Level 2: Практика (Пройден активный ввод Typing / Active recall)
   │
   ▼
Level 3: Уверенность (Stability >= 14 дней, accuracy >= 85%)
   │
   ▼
Level 4: Освоено (Mastered - Контекстное использование Context Production / High Stability)
```

---

## 📊 Требования к каждому уровню Mastery

| Уровень                   | Обязательные доказательства (Evidence)                                              | Требования к Stability / Lapses                                 |
| :------------------------ | :---------------------------------------------------------------------------------- | :-------------------------------------------------------------- |
| **Level 0 (Новый)**       | Нет повторений.                                                                     | —                                                               |
| **Level 1 (Знакомство)**  | Хлатя бы 1 успешное повторение (любой режим).                                       | —                                                               |
| **Level 2 (Практика)**    | Наличие успешных ответов в режимах активного воспроизведения (`typing`, `drawing`). | `lapses <= 2`                                                   |
| **Level 3 (Уверенность)** | Подтвержденное воспроизведение на интервале повторений.                             | `Stability >= 14 дней`, `Accuracy >= 85%`                       |
| **Level 4 (Освоено)**     | Успешное выполнение `context-production` (или `kanji-writing` для кандзи).          | `Stability >= 30 дней`, `Lapses == 0` за последние 5 повторений |

> [!NOTE]
> Свежий зафиксированный сбой (lapse) временно понижает расчетный уровень Mastery элемента до 1 или 2 до восстановления стабильности.
