# Knowledge Model — Предметная Модель Знаний

В этом документе опиcана структура единиц знаний (Knowledge Items) и правила формирования карточек навыков (Skill Cards) в `src/knowledge-model.js`.

---

## 🗂️ Единицы знаний (Knowledge Items)

Учебный материал делится на 3 типа единиц знаний (`knowledgeType`):

1. **Vocabulary Item (`vocabulary`)**: Словесная единица (слово, выражение) с кандзи, кана, типом речи и значением.
2. **Grammar Item (`grammar`)**: Грамматическая тема, включая правила, сопряжения глаголов и конструкции.
3. **Kanji Item (`kanji`)**: Иероглифическая карточка с порядком черт, оными/кунными чтениями и примерами.

---

## 🎴 Карточки навыков (Skill Cards)

Каждый элемент знаний порождает одну или несколько карточек навыков (`skill`).

Идентификатор карточки `cardId` всегда формируется детерминированно:

```javascript
cardId = `${itemId}:${skill}`;
```

### Таблица доступных навыков (`skill`):

| Навык (`skill`)      | Назначение                                                          | Допустимые учебные режимы   | Формирование `cardId` (Пример)    |
| :------------------- | :------------------------------------------------------------------ | :-------------------------- | :-------------------------------- |
| `vocabulary-meaning` | Распознавание значения слова по звучанию/написанию.                 | `multiple-choice`, `typing` | `genki1_l1_v1:vocabulary-meaning` |
| `vocabulary-reading` | Распознавание чтения кандзи-слова на кане.                          | `multiple-choice`, `typing` | `genki1_l1_v1:vocabulary-reading` |
| `kanji-writing`      | Написание иероглифа черта за чертой.                                | `drawing`                   | `kanji_001:kanji-writing`         |
| `context-production` | Активное создание формы слова/грамматики в контекстном предложении. | `context-production`        | `genki1_l1_v1:context-production` |
| `particle-selection` | Выбор подходящей частицы в предложении.                             | `particle-quiz`             | `genki1_l2_g1:particle-selection` |
| `sentence-building`  | Сборка предложения из словесных блоков.                             | `sentence-building`         | `genki1_l2_g2:sentence-building`  |

## 🔒 Состояния карточки (`planLocked`, `suspended`, `orphaned`)

- **`planLocked`**: Карточка принадлежит главе, доступ к которой ещё не открыт согласно текущему учебному плану или этапу staged opening.
- **`suspended`**: Пользователь вручную приостановил карточку в словаре.
- **`orphaned`**: Запись карточки существует в `state.srs`, но сам элемент знаний удалён или изменён в контенте.
