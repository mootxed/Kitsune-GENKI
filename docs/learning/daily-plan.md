# Daily Plan — Дневной План и Границы Дня

Документ опиcывает устройство ежедневного плана `dailySnapshot` и определение границ локального дня (`src/daily-plan.js`, `src/local-date.js`).

---

## 🌅 Граница локального учебного дня (Day Boundary)

- Для предотвращения сброса ежедневного прогресса в полночь при поздних занятиях, смена учебного дня происходит в **04:00 по локальному времени пользователя** (`getLocalStudyDay()`).
- Все занятия до 04:00 утра относятся к предыдущему локальному учебному дню.

---

## 📋 Снапшот дневного плана (`dailySnapshot`)

Каждый день при первом входе создаётся или обновляется объкт `state.dailySnapshot`:

```javascript
{
  date: "2026-07-27",
  reviewTask: {
    total: 20,         // Общее количество повторений, запланированных на день
    completed: 15,     // Выполнено повторений
    frozenCardIds: [...] // Зафиксированные ID задолженных карточек
  },
  newItemsTask: {
    total: 5,          // Запланировано новых элементов
    completed: 5       // Освоено новых элементов
  },
  completedEvents: [...]
}
```

Выполнение дневного плана считается достигнутым при завершении обеих задач (`reviewTask` и `newItemsTask`).
