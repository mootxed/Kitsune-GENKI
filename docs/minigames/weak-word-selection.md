# Weak Word Selection — Алгоритм Выбора Проблемных Слов

Документ описывает логику отбора проблемных (слабых) слов для мини-игр (`src/minigame-weakness.js`, `src/minigame-word-selectors.js`).

---

## 🎯 Алгоритм вычисления показателя слабости (Weakness Score)

При формировании набора слов для кроссворда или поиска слов фильтр отдаёт приоритет элементам с наибольшим индексом проблемности:

$$ \text{Weakness Score} = (10 - \text{Mastery Level}) \times 2 + \text{Lapses Count} \times 3 - \min(\text{Stability}, 10) $$

### Дополнительные фильтры:

- **`planLocked` check**: Из выборки исключаются карточки ещё не задействованных глав.
- **Fallback**: Если проблемных слов недостаточно для заполнения сетки кроссворда, подборка автоматически дополняется случайно выбранными открытыми словами.
