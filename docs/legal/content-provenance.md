# Реестр происхождения контента KotoKitsu

Документ описывает принципы учета и классификации учебного контента в приложении **KotoKitsu**.

## Классификация заданий

Все задания дополнительной практики классифицируются по типам происхождения:

1. `original`: Авторские задания, самостоятельно сформулированные авторами KotoKitsu.
2. `generic-language-fact`: Общеизвестные грамматические факты японского языка (частицы, спряжения, базовая грамматика).
3. `adapted-structure`: Адаптированные структуры упражнений с оригинальным текстом.
4. `possibly-derived`: Задания, требующие дополнительной ручной проверки автором.
5. `confirmed-third-party`: Сторонние материалы с известной лицензией.
6. `unknown`: Задания с неизвестным происхождением (отправляются на проверку).

## Изоляция и точечная фильтрация

Если конкретное задание признано сомнительным (`possibly-derived` / `unknown`), оно исключается точечно (`productionEligible: false`), при этом весь файл или остальной курс продолжает функционировать.

Полный машиночитаемый реестр находится в [CONTENT_PROVENANCE.json](../../CONTENT_PROVENANCE.json).
