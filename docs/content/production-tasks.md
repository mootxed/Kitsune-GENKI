# Production Tasks Schema — Схема Заданий Контекстной Продукции

В этом документе описывается структура кураторских заданий для режима Context Production (`src/production-context.js`).

---

## 📝 Пример задания

```json
{
  "id": "prod_l3_v1_01",
  "focusItemId": "genki1_l3_v1",
  "prompt": "図書館で本を ___。",
  "meaningCue": "read (past affirmative)",
  "requiredForm": "よみました",
  "acceptedAnswers": ["よみました", "読んだ", "読みました"],
  "chapter": 3
}
```

---

## 🛑 Запрещенные неоднозначные задания

При создании контекстных заданий категорически запрещается создавать пропуски с неоднозначным контекстом (где подходит сразу 5 разных глаголов). Подсказка `meaningCue` и грамматический контекст должны однозначно указывать на требуемую форму.
