# Глобальный token index

`public/data/dictionary/token-index.json` сопоставляет нормализованную
поверхностную форму с массивом `dictionaryId`. Генератор добавляет словарную и
письменную формы, чтение и поддержанные формы спряжения. Порядок ключей и
кандидатов детерминирован.

Один токен может иметь несколько кандидатов. Resolver возвращает
`resolved`, `ambiguous` или `missing`; он не выбирает первый элемент молча.
Контекст текущего/завершённого курса и AI hint влияют только на ranking, но не
фильтруют глобальную базу.

Порядок источников:

1. встроенная глобальная база;
2. глобальные пользовательские AI-entry;
3. контекстный AI fallback.

Неподдержанная форма остаётся `missing` и может быть обработана AI-потоком.
Добавлять предположительно правильные формы вручную в generated index нельзя:
расширяйте проверенный conjugator или aliases и повторяйте
`npm run build:dictionary`.
