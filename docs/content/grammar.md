# Grammar Schema — Схема Грамматических Тем

Документ описывает структуру грамматических тем в массиве `grammar` файлов уроков.

---

## 📝 Пример структуры грамматической темы

```json
{
  "id": "genki1_l1_g2",
  "title": "X wa Y desu (X is Y)",
  "titleJa": "X は Y です",
  "chapter": 1,
  "explanation": "The particle は indicates the sentence topic...",
  "structure": "Topic は Value です",
  "examples": [
    {
      "japanese": "たなかさんはせんせいです。",
      "english": "Mr. Tanaka is a teacher."
    }
  ]
}
```
