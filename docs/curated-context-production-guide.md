# Руководство по созданию curated context-production заданий

`context-production` — это режим активного воспроизведения, в котором пользователь самостоятельно составляет или вводит японское предложение или фразу с изучаемым словом в заданном контексте.

---

## 1. Как выбрать focus word (`focusItemId`)

1. **Соответствие слову**: Задание создаётся под конкретное изучаемое слово из словаря урока. `focusItemId` должен строго совпадать с `id` слова (например, `L1_V023`).
2. **Освоенность базовых навыков**: Слово должно подходить для контекстного употребления в простой фразе текущего урока.
3. **Исключения**: Не создавайте задания для междометий или суффиксов, для которых невозможно построить осмысленное законченное предложение уровня текущей главы.

---

## 2. Как сформулировать prompt и meaningCue

1. **Русский prompt**: Ясное и однозначное задание на русском языке, например:  
   `«Скажите по-японски: “Я студент”.»`
2. **meaningCue**: Дополнительная подсказка по контексту/словам, если перевод допускает вариативность, например:  
   `«Используйте слово “студент” и вежливую связку.»`
3. **Запрет прямой подсказки**: В prompt и meaningCue категорически запрещено давать готовый японский ответ.

---

## 3. Как перечислять acceptedAnswers

1. **Варианты написания**: Перечислите все корректные варианты написания фраз (кандзи и хираганой), например:  
   `["わたしはがくせいです", "私は学生です"]`
2. **Форма ответа**: Все варианты в `acceptedAnswers` должны использовать строго одну и ту же грамматическую форму (например, вежливую утвердительную).
3. **Отсутствие неоднозначности**: Не добавляйте варианты с другими частицами или меняющие смысл фразы.

---

## 4. Как задавать requiredForm

Укажите требуемую грамматическую форму:

```json
{
  "type": "copula",
  "politeness": "polite",
  "tense": "non-past",
  "polarity": "affirmative"
}
```

Допустимые значения:

- `politeness`: `"polite"` (вежливая), `"plain"` (простая)
- `polarity`: `"affirmative"` (утверждение), `"negative"` (отрицание), `"interrogative"` (вопрос)
- `tense`: `"non-past"` (наст./буд.), `"past"` (прошедшее)
- `type`: `"copula"` (связка です), `"verb"` (глагол), `"i-adj"`, `"na-adj"`, `"noun_phrase"`

---

## 5. Проверка естественности и правила валидации

- Фраза должна быть 100% грамматически корректной и естественной.
- Запрещено использовать грамматику из будущих глав.
- Валидация выполняется перед сборкой с помощью `npm run validate:grammar-quizzes`.
