# Events & Review Journal — Журнал Событий

В этом документе описана архитектура журнала повторений (`review_log` в `src/review-journal.js` и `src/review-log.js`).

---

## 📝 Структурная схема Review Event

Каждое повторение карточки генерирует событие review event:

```javascript
{
  eventId: "rev_1722097800000_a8f1b2", // Уникальный UUID/хеш события
  cardId: "genki1_l1_v1:vocabulary-meaning", // Идентификатор карточки
  timestamp: "2026-07-27T16:30:00.000Z",   // Время выполнения повторения
  rating: 3,                          // 1: Again, 2: Hard, 3: Good, 4: Easy
  quality: 3,                         // Внутренняя оценка ответа
  responseTimeMs: 2400,                // Время ответа в миллисекундах
  mode: "active-typing",              // Режим, в котором был дан ответ
  stateBefore: {                      // Состояние FSRS до ответа
    stability: 2.1,
    difficulty: 5.0
  },
  stateAfter: {                       // Состояние FSRS после ответа
    stability: 4.5,
    difficulty: 4.8
  }
}
```

---

## 🛡️ Идемпотентность и Компактизация (Compaction)

1. **Идемпотентность**: Каждое событие имеет уникальный `eventId`. Повторный вызов сохранений с тем же `eventId` игнорируется.
2. **Компактизация журнала**: При превышении размером журнала порога (более 10,000 событий) вызов `compactReviewJournal()` сохраняет сводную статистику по старым событиям и удаляет детальные логи старше 90 дней, экономя дисковое пространство.
