# Persistence & Outbox — Синхронизация и Отложенная Запись

Документ описывает механики устойчивого сохранения данных и межвкладочной синхронизации.

---

## 📦 Transactional Outbox Pattern

При совершении учебных действий пользовательский интерфейс обновляет состояние в памяти мгновенно, не дожидаясь завершения операции ввода-вывода диска:

```text
[UI Answer Action]
       │
       ▼
[In-Memory Store Update (Immediate UI Refresh)]
       │
       ▼
[Push to Outbox Queue] ──► [IndexedDB Async Transaction] ──► [Confirmed]
```

Если транзакция прерывается (например, при неожиданном закрытии приложения), при следующем старте Outbox восстанавливает незафиксированные записи из журнала.

## 🔄 Межвкладочная синхронизация (`src/tab-sync.js`)

- Использование `BroadcastChannel('kitsune_tab_sync')` позволяет транслировать уведомления о состоявшихся сохранениях между несколькими открытыми вкладками браузера.
- При получении сообщения неактивные вкладки обновляют ссылку на актуальный снапшот состояния из IndexedDB, исключая состояние гонки (Race conditions).
