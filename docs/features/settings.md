# Settings Screen — Панель Настроек

Документ описывает функции экрана настроек (`ui/settings.js`).

---

## ⚙️ Управляемые параметры

- **Тема оформления**: Светлая, Темная, Системная.
- **Дневной лимит повторений**: Настройка максимума карточек в день.
- **Настройки звука**: Автопроизношение при ответе, громкость аудио.
- **Управление данными**:
  - Экспорт бэкапа в JSON.
  - Импорт бэкапа с валидацией версий.
  - Сброс локального прогресса (Reset All State).
