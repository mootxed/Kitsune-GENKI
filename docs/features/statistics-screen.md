# Statistics Screen — Экран Аналитики и Статистики

Документ описывает интерфейс экрана статистики (`ui/statistics.js`, `src/statistics/statistics-view-model.js`).

---

## 📈 Визуализируемые блоки и графики

1. **Общий прогресс**: Процент пройденного контента, суммарный XP, текущий стрик.
2. **График удерживаемости (Retention Graph)**: Динамика фактической точности ответов по дням.
3. **Распределение Мастерства**: Гистограмма количества элементов на уровнях 0, 1, 2, 3 и 4.
4. **Прогноз нагрузки (Forecast Chart)**: Количество задолженных карточек, ожидаемых к повторению на ближайшие 7, 14 и 30 дней.
5. **Список проблемных карточек (Problem Cards)**: Карточки с наибольшим числом сбоев (`lapses > 2`).
