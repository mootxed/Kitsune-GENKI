# Onboarding Flow — Процесс Начальной Настройки

Документ описывает первичный сценарий знакомства пользователя с приложением (`ui/onboarding.js`, `src/onboarding-state.js`).

---

## 🚀 Пошаговый мастер настройки

1. **Приветствие**: Краткая презентация возможностей приложения.
2. **Оценка начального уровня**: Выбор уровня знаний (Абсолютный новичок, Зная кану, Изучал Genki I ранише).
3. **Формирование целей**: Задание доступного ежедневного времени (10, 20 или 30 минут) и желаемой даты завершения курса.
4. **Генерация плана**: Инициализация `state.userPlan`, устанновка флага `onboardingCompleted = true` и автоматический перенаправление на `#/home`.
