# Optional AI Integration — AI Story Generator

В этом документе опиcана необязательная функция генерации историй с использованием внешнего OpenRouter API (`ui/ai-story.js`, `src/ai-story-parser.js`, `src/ai-story-schema.js`).

---

## 🛑 Четкое разделение: Offline Core vs Optional Network AI

> [!IMPORTANT]
> Весь базовый функционал **Kitsune-GENKI** (обучение, FSRS, сессии, словарь, мини-игры) на 100% автономен и не требует интернет-соединения или сторонних API.
> Интеграция с OpenRouter API является **необязательным сетевым расширением**.

---

## 🤖 AI Story Generator

- **Назначение**: Сгенерировать связный короткий рассказ на японском языке с использованием слов текущей изучаемой главы.
- **Требования**: Наличие подключения к сети и введенного ключа `VITE_OPENROUTER_API_KEY` в настройках.
- **Парсинг и валидация**: Ответ от модели верифицируется через схему Zod (`src/ai-story-schema.js`) для предотвращения галлюцинаций в структуре JSON.
- **Offline Fallback**: При отсутствии сети или ключа пользователю предлагаются заранее подготовленные офлайн-истории из `public/data/stories/`.
