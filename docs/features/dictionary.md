# Dictionary Feature — Интерактивный Словарь

Документ описывает устройство интерактивного словаря (`ui/flashcards/dictionary.js`, `ui/flashcards/dictionary-modal.js`).

---

## 🔍 Интерактивные возможности словаря

1. **Мгновенный поиск**: Фильтрация по кандзи, кане, ромадзи и значению (английскому/русскому).
2. **Фильтры по главам и частям речи**: Ограничение списка конкретной главой Genki.
3. **Карточка элемента (Modal View)**:
   - Отображение индикаторов уровня Mastery (Level 0..4).
   - Отрисовка анимации написания иероглифа через `hanzi-writer`.
   - Воспроизведение произношения при наличии аудиофайла.
   - Переключатель ручной приостановки карточки (`suspended`).
