# Audio Subsystem — Воспроизведение Аудио

Документ описывает подсистему аудио сопровождения произношения (`src/audio-helper.js`).

---

## 🔊 Источники аудио и Fallback

1. **Предзагруженные MP3-файлы**: Воспроизведение оригинальных аудиозаписей из каталога `public/data/audio/`.
2. **Web Speech API Fallback**: Если MP3-файл отсутствует, используется нативный речевой синтезатор браузера (`window.speechSynthesis`) с локалью `ja-JP`.

---

## 🔒 Ограничения Autoplay

При первом входе воспроизведение аудио требует предварительного пользовательского клика (Autoplay Policy браузеров). Ошибки воспроизведения перехватываются без блокирования интерфейса сессии.
