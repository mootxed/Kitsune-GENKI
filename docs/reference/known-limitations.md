# Known Limitations — Известные Технические Ограничения

В этом документе приведены официально подтвержденные текущие технические ограничения и особенности проекта.

---

## 📌 Подтверждённые ограничения

1. **Alpha Status**: Приложение находится в фазе активной альфа-разработки (`v0.1.0-alpha`).
2. **Cross-Tab Storage Sync**: Система включает координирующую блокировку через BroadcastChannel и оптимистичные проверки ревизий state. Вторая открытая вкладка автоматически переходит в режим только чтение для предотвращения гонок.
3. **AI Feature Dependency**: Функция AI Story Generator требует внешнего подключения к интернет и собственного API-ключа OpenRouter.
4. **Context Production Coverage**: Кураторские контекстные задания интегрированы для всех 12 модулей базового каталога KotoKitsu.
5. **Speech Synthesis Quality**: Качество синтеза речи в браузере при использовании fallback SpeechSynthesis зависят от установленных в ОС системных голосов.
