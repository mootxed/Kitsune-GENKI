# Card Schema Reference — Справочник Схемы Карточки FSRS

Документ опиcывает структуру объекта FSRS карточки внутри `state.srs[cardId]`.

---

## 🎴 Объект карточки FSRS

```javascript
{
  due: "2026-07-28T09:00:00.000Z",   // Дата и время следующего показа
  stability: 4.25,                    // Зафиксированная стабильность в днях
  difficulty: 5.12,                   // Сложность элемента (1.0 .. 10.0)
  elapsed_days: 2,                    // Прошло дней с последнего повторения
  scheduled_days: 3,                  // Запланировано дней до повторения
  reps: 4,                            // Общее число повторений
  lapses: 0,                          // Число сбоев (ошибок на этапе Review)
  state: 2,                           // 0: New, 1: Learning, 2: Review, 3: Relearning
  last_review: "2026-07-25T09:00:00.000Z" // Время последнего повторения
}
```
