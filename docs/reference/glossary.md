# Domain Glossary — Глоссарий Терминов

В этом документе содержатся определения ключевых доменных терминов проекта **KotoKitsu**.

---

## 📖 Словарь терминов

- **Knowledge Item (KI)**: Атомарная единица обучающего материала (слово, грамматическая тема или кандзи).
- **Skill Card**: Конкретная карточка навыка (например, `vocabulary-meaning` или `context-production`), сгенерированная из KI.
- **FSRS (Free Spaced Repetition Scheduler)**: Алгоритм расчёта оптимальных интервалов повторения на основе показателей Stability и Difficulty.
- **Stability ($S$)**: Прогнозируемый временной интервал в днях, в течение которого сохраняется 90% вероятность успешного припоминания.
- **Difficulty ($D$)**: Оценка относительной сложности учебного материала для пользователя.
- **Retrievability ($R$)**: Вероятность успешного припоминания материала в данный момент времени.
- **Mastery Level**: Многокритериальный показатель освоения материала на практике (от 0 - "Не изучен" до 4 - "Освоен").
- **Lapse**: Сбой памяти, при котором карточка из статуса Review переходит в status Relearning из-за ошибки (Again).
- **Staged Skill Opening**: Поэтапное открытие новых слов главы по учебным дням для предотвращения информационной перегрузки.
- **Supplemental Practice**: Дополнительные учебные активности (мини-игры), результаты которых не изменяют FSRS-параметры карточек.
