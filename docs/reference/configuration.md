# Configuration Reference — Справочник Конфигурации

Документ описывает конфигурационные файлы сборщика Vite, Vitest и Playwright.

---

## ⚙️ Конфигурационные файлы

- **`vite.config.js`**: Настройки сборщика Vite, оптимизация зависимостей, base path.
- **`vitest.config.js`**: Настройки тест-раннера Vitest, подключения моков `tests/setup-mocks.js` и среды `jsdom`.
- **`playwright.config.js`**: Конфигурация E2E тестов Playwright, порты dev-сервера и браузеры.
