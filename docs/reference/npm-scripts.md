# NPM Scripts Reference — Справочник NPM Скриптов

В этом документе выверены все существующие скрипты из `package.json`.

---

## 🛠️ Таблица NPM скриптов

| Команда                            | Назначение                                           | Когда запускать                      |
| :--------------------------------- | :--------------------------------------------------- | :----------------------------------- |
| `npm run dev`                      | Запуск локального сервер разработки Vite.            | При повседневной разработке.         |
| `npm run build`                    | Валидация контента и сборка проекта в папку `dist/`. | Перед релизом или пушем.             |
| `npm run preview`                  | Просмотр собранного бандла из `dist/`.               | Для проверки продакшн сборки.        |
| `npm test`                         | Запуск всех Vitest тестов 1 раз.                     | При внесении любых изменений в код.  |
| `npm run test:watch`               | Запуск Vitest в режиме отслеживания.                 | Во время написания тестов.           |
| `npm run test:coverage`            | Генерация отчёта о покрытии кода тестами.            | Для анализа покрытия.                |
| `npm run test:e2e`                 | Запуск сквозных тестов Playwright.                   | Перед отправкой PR.                  |
| `npm run validate:grammar-quizzes` | Проверка валидности грамматических тестов.           | Автоматически в prebuild.            |
| `npm run build:dictionary`         | Генерация глобальных статей, refs и token index.     | После изменения словарного контента. |
| `npm run validate:dictionary`      | Проверка словаря, aliases и course refs.             | Автоматически в prebuild.            |
| `npm run build:kanji`              | Сборка данных кандзи для `hanzi-writer`.             | Автоматически в prebuild.            |
| `npm run docs:check`               | Проверка битых ссылок и путей в документации.        | При редактировании `/docs`.          |
| `npm run lint`                     | Проверка кода с помощью ESLint.                      | Перед коммитом.                      |
| `npm run lint:fix`                 | Автоматическое исправление ошибок ESLint.            | При необходимости.                   |
| `npm run format`                   | Форматирование всего проекта с помощью Prettier.     | Перед коммитом.                      |
| `npm run format:check`             | Проверка соблюдения правил Prettier.                 | В CI.                                |
