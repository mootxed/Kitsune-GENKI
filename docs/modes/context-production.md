# Context Production Mode — Режим Контекстной Продукции

Документ описывает режим активного создания грамматических форм и слов в контексте (`context-production` в `ui/flashcards/card-modes.js`, `src/production-context.js`).

---

## 🎯 Назначение и Архитектурная ценность

Контекстная продукция — высшая ступень освоения навыка (необходимая для достижения **Mastery Level 4**).

Пользователь должен не просто узнать слово, а самостоятельно сформулировать правильную грамматическую форму слова (например, спряжение глагола в te-form или past-negative) в предложении.

---

## 📝 Структурный пример задания

```javascript
{
  id: "prod_g1_l3_v1",
  focusItemId: "genki1_l3_v1",     // Целевое слово (например, 食べる)
  prompt: "きのう、すшиを ___。",       // Предложение с пропуском
  meaningCue: "ate (past affirmative)", // Подсказка по значению и форме
  requiredForm: "たべました",        // Обязательная целевая форма
  acceptedAnswers: ["たべました", "食べた"] // Альтернативные валидные формы
}
```

---

## ⚖️ Правила валидации и FSRS

- Ответ сверяется с `requiredForm` и массивом `acceptedAnswers`.
- Точное совпадение квалифицирует карточку на `Rating.Good`.
- При отсутствии созданных кураторских заданий для данного элемента режим автоматически заменяется на активный ввод (`active-typing`) с пометкой текущего ограничения.
