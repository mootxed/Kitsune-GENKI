# Sentence Building Mode — Режим Конструирования Предложений

Документ описывает режим сборки предложений из фрагментов (`sentence-building` в `ui/flashcards/card-modes.js`).

---

## 🧩 Назначение и Поведение

- **Проверяемый навык**: `sentence-building` (синтаксический порядок слов SOV).
- **UI Flow**: Пользователю даётся перевод предложения на русский или английский язык и набор перемешанных блоков-слов на японском языке.
- Пользователь поочерёдно нажимает на блоки, собирая правильно структурированное предложение.
- При ошибке порядка блоков выводится подсказка о правильной структуре темы и сказуемого.
