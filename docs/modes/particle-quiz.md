# Particle Quiz Mode — Режим Выбора Частиц

Документ описывает специализированный режим практики падежных и грамматических частиц (`ui/flashcards/card-modes.js`, `src/particle-templates.js`).

---

## 🎯 Назначение и Поведение

- **Проверяемый навык**: `particle-selection`.
- **UI Flow**: Пользователю выводится японское предложение с пропущенной частицей (`は`, `が`, `を`, `に`, `で`, `へ` и т.д.).
- Варианты ответов формируются из близких грамматических частиц.
- При правильном выборе выводится краткая справка о роли выбранной частицы в данном контексте из базы `particles-dictionary.json`.
