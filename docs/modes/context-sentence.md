# Context Sentence Mode — Режим Контекстного Чтения

Документ описывает режим чтения слов в реальных предложениях (`ui/flashcards/card-modes.js`, `src/production-context.js`).

---

## 📖 Назначение и Поведение

- **Проверяемый навык**: Чтение и понимание слова в контексте японского предложения.
- **UI Flow**: Пользователю демонстрируется законченное предложение с выделенным словом. Пользователь должен ввести чтение выделенного слова на кане или выбрать его перевод.
- **Аудио сопровождение**: Автоматическое или ручное воспроизведение произношения предложения через Web Speech API / HTML5 Audio.
