# Drawing Mode — Режим Рукописного Ввода Кандзи

Документ описывает режим начертания иероглифов (`drawing` в `ui/flashcards/drawing-mode.js`).

---

## 🖌️ Технологический стек

Используется библиотека `hanzi-writer` с адаптивным набором японских иероглифов `@k1low/hanzi-writer-data-jp`.

---

## 🎯 Правила проверки начертания

1. **Соблюдение порядка черт**: Валидатор проверяет направление и порядок написания каждой черты.
2. **Толерантность ошибок**:
   - Первая неверная черта вызывает визуальное предупреждение без сброса карточки.
   - Более 3 неверных попыток начертания черты квалифицируют карточку как `Rating.Again`.
   - Полностью правильное самостоятельное написание квалифицируется как `Rating.Good`.
