# Getting Started — Разворачивание и Запуск

Данное руководство предназначено для быстрого разворачивания локальной среды разработки проекта **Kitsune-GENKI**.

---

## 📋 Требования к окружению

- **Node.js**: Версия `>= 22.0.0` (указана в `package.json` `engines`).
- **Package Manager**: `npm` (версия 10+).
- **Браузер**: Современный браузер с поддержкой ES Modules, IndexedDB и Service Worker (Chrome, Firefox, Safari, Edge).

---

## 🚀 Пошаговая установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/user/kitsune-genki.git
cd kitsune-genki
```

### 2. Проверка версии Node.js

Если вы используете NVM (Node Version Manager):

```bash
nvm use
```

### 3. Установка зависимостей

```bash
npm install
```

---

## 💻 Запуск локального сервера разработки

Для запуска Vite dev-сервера выполните:

```bash
npm run dev
```

После этого приложение доступно по адресу: `http://localhost:5173/` (или другому порту, указанному Vite в консоли).

---

## 🔍 Быстрая проверка работоспособности

Перед началом разработки убедитесь, что все тесты и проверки проходят успешно:

```bash
# 1. Запуск Vitest юнит- и интеграционных тестов
npm test

# 2. Проверка валидности грамматических тестов и генерация данных кандзи
npm run prebuild

# 3. Проверка Markdown-документации и ссылок
npm run docs:check

# 4. Проверка форматирования и линтинга
npm run lint
npm run format:check
```

---

## 🛠️ Переменные окружения (Environment Variables)

По умолчанию проект **не требует `.env` файлов** для базовой работы и обучения.

Если вам требуется использовать необязательные сетевые AI-функции (генерация связных историй AI Story через OpenRouter), вы можете указать ключ в настройках интерфейса (`#/settings`) либо задать переменную среды Vite:

Пример `.env.example`:

```env
VITE_OPENROUTER_API_KEY=your_optional_api_key_here
```
