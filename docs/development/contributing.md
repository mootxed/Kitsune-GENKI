# Contributing Guidelines — Участие в Разработке

Спасибо за интерес к участию в развитии **Kitsune-GENKI**!

---

## 📌 Чек-лист перед отправкой Pull Request (PR)

Перед отправкой изменений убедитесь, что вы выполнили следующие шаги:

1. **Запустили юнит-тесты**: `npm test` завершается со 100% успехом.
2. **Проверили линтинг и стиль**: `npm run lint` и `npm run format:check` не выявляют ошибок.
3. **Проверили документацию**: Добавили или обновили Markdown-документы в `/docs` для новых фич и выполнили `npm run docs:check`.
4. **Убедились в успешности сборки**: `npm run build` проходит без ошибок.
5. **Не нарушили архитектурные инварианты**:
   - Нет прямых мутаций глобального состояния вне `store.js`.
   - Нет небезопасного `innerHTML`.
   - Все новые функции в `src/` снабжены автотестами.

---

## 💬 Сообщения коммитов (Commit Messages)

Рекомендуется использовать стандарт Conventional Commits:

- `feat: ...` — добавление нового функционала или учебного режима.
- `fix: ...` — исправление бага или ошибки валидации.
- `docs: ...` — изменение документации.
- `test: ...` — добавление или обновление тестов.
- `refactor: ...` — рефакторинг кода без изменения внешней функциональности.
