# Offline Mode — Автономный Режим

Документ описывает поведение веб-приложения при полном отсутствии интернет-соединения.

---

## 📴 Функциональность в автономном режиме

- **Учебные сессии**: Полностью функциональны. Карточки, FSRS и сохранения работают автономно через IndexedDB.
- **Словарь**: Работает в полном объёме из локального кэша контента.
- **Мини-игры**: Разгадывание кроссвордов и поиск слов функционируют офлайн.
- **Offline Fallback Page**: При первой некорректной попытке зайти на некешированный внешний URL показывается страница `public/offline.html`.
