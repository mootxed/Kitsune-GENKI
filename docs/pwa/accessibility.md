# Global Accessibility Standards — Стандарты Доступности

Документ описывает реализацию стандартов доступности по всему приложению (`src/a11y-helpers.js`).

---

## ♿ Соответствие WCAG 2.2 AA

Приложение стремится соответствовать стандарту WCAG 2.2 AA в основных сценариях использования.

### Реализованные стандарты:

- **Управление фокусом**: Хелпер `trapFocus(dialogElement)` удерживает фокус клавиатуры внутри активных модальных окон.
- **Анонс маршрутов**: Смена страниц роутера анонсируется для скринридеров через скрытый элемент `aria-live="assertive"`.
- **Японская локаль**: Все блоки с японским текстом содержат атрибут `lang="ja"`.
