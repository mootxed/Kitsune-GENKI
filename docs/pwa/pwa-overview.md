# PWA Overview — Обзор Progressive Web App

Проект **Kitsune-GENKI** спроектирован как полноценное автономное приложение Progressive Web Application (PWA).

---

## 📱 Ключевые возможности PWA

- **Установка на экран**: Приложение может быть установлено на рабочий стол мобильного устройства или ПК без вызова магазинов приложений.
- **Offline-First**: Полная автономная доступность после первого открытия благодаря Service Worker (`public/sw.js`).
- **Offline Dictionary**: manifest, entries, token index и aliases сохраняются в
  отдельном словарном кеше и не вытесняются course LRU.
- **Мобильная адаптируемость**: Responsive UI для смартфонов, планшетов и настольных компьютеров.
