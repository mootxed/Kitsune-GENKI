# Caching Strategies — Стратегии Кеширования

Документ описывает сетевые стратегии кеширования в Service Worker.

---

## 📊 Таблица применяемых стратегий

| Тип ресурса                 | Стратегия кеширования              | Обоснование                                                 |
| :-------------------------- | :--------------------------------- | :---------------------------------------------------------- |
| **App Shell (HTML/JS/CSS)** | **Stale-While-Revalidate**         | Быстрая загрузка из кэша с асинхронным фоновым обновлением. |
| **Учебные JSON уроки**      | **Cache First с Network Fallback** | Материалы учебника статичны и гарантируют офлайн доступ.    |
| **Аудиоклипы MP3**          | **Cache First**                    | Кешируются при первом воспроизведении для снижения трафика. |
| **Внешний OpenRouter API**  | **Network Only**                   | Сетевой вызов без кеширования ответов LLM в SW.             |
