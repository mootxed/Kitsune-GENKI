# ADR-0001: Использование Vanilla JavaScript и Vite

- **Статус**: Принято
- **Дата**: 2026-07-15

---

## Контекст

При проектировании KotoKitsu требовалось обеспечить максимальную производительность, минимальный размер финального бандла для моментальной загрузки на мобильных устройствах и независимость от стремительно устаревающих фреймворков.

## Решение

Отказаться от React/Vue/Angular в пользу нативного Vanilla JavaScript (ES2022 / ES Modules) в сочетании со сборщиком Vite 5.

## Последствия

- **Плюсы**: Мгновенный запуск PWA, нулевые накладные расходы виртуального DOM, минимальный бандл.
- **Минусы**: Необходимость явного написания логики роутинга и рендеринга представений.
