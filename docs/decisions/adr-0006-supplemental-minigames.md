# ADR-0006: Изоляция Мини-Игр от FSRS Повторений

- **Статус**: Принято
- **Дата**: 2026-07-22

---

## Контекст

Мини-игры (кроссворды, поиск слов) предназначены для развлечения и игровой практики. Принятие решений в играх может происходить методом угадывания или подбора.

## Решение

Объявить все мини-игры **вспомогательной практикой (Supplemental Practice)**. Результаты прохождения игр не создают FSRS review events и не изменяют `stability`/`due` карточек.

## Последствия

- **Плюсы**: Исключение искажения интервалов повторения из-за угадываний в играх.
- **Минусы**: Игры служат только для дополнительного закрепления и получения XP.
