# Repository Structure — KotoKitsu

В этом документе описана организация каталогов и ключевых файлов проекта **KotoKitsu**.

---

## 📁 Карта каталогов верхнего уровня

```text
/
├── .github/              # GitHub Actions CI/CD workflows
├── docs/                 # Системная техническая документация (текущая)
├── public/               # Статические ресурсы, PWA manifest, Service Worker и JSON контент
│   ├── data/             # Индексированный контент учебника Genki, грамматика, аудио
│   └── sw.js             # Service Worker (кеширование и offline-first)
├── scripts/              # Скрипты сборки контента, валидации и проверки документации
├── src/                  # Ядро доменной логики, работа с данными, FSRS и статистика
│   └── statistics/       # Модули сбора и вычисления статистических метрик
├── state/                # Хранилище состояния приложения (Redux-like Store, миграции)
├── ui/                   # Компоненты интерфейса, представления страниц и карточки
│   └── flashcards/       # Рендереры учебных режимов, сессии и модальные окна
├── tests/                # Тестовые наборы (Vitest unit/integration и Playwright E2E)
│   ├── e2e/              # E2E и accessibility спецификации Playwright
│   └── statistics/       # Тесты статистических модулей
├── index.html            # Единственный HTML-шаблон (Single Page Application)
├── app.js                # Точка входа веб-приложения и инициализация
├── router.js             # Роутер навигации по маршрутам
├── srs.js                # Обёртка над ts-fsrs и алгоритм адаптации SM-2 → FSRS
├── session-manager.js    # Оркестратор текущей учебной сессии
├── studyplan.js          # Доменная модель генерации и пересчета учебных планов
├── achievements.js       # Система ачивок и наград
├── quests.js             # Квесты и ежедневные задания
├── services.js           # Сервис интеграции (bridge между store, db и UI)
├── styles.css            # Главный таблицу стилей (Vanilla CSS)
└── vite.config.js        # Конфигурация сборщика Vite
```

## 🔍 Ответственность главных директорий

### `src/` — Доменная логика и инфраструктура

Содержит чистые функции бизнес-логики, алгоритмы, сервисы работы с IndexedDB и математические расчёты.

| Модуль / Файл                   | Назначение                                                                       | Связанные тесты                        |
| :------------------------------ | :------------------------------------------------------------------------------- | :------------------------------------- |
| `src/db.js`                     | Обёртка над IndexedDB (`KitsuneGenkiDB` v4), управление транзакциями и fallback. | `tests/db.test.js`                     |
| `src/migration.js`              | Автоматическая миграция данных из legacy localStorage в IndexedDB.               | `tests/migration.test.js`              |
| `src/knowledge-model.js`        | Фабрика `cardId`, сопоставление `itemId` + `skill` + `knowledgeType`.            | `tests/domain-safeguards.test.js`      |
| `src/mastery.js`                | Расчёт уровня освоения навыка (Mastery Level 0..4) по истории повторений.        | `tests/mastery.test.js`                |
| `src/daily-plan.js`             | Формирование снапшота дневного плана и дневных границ (Day boundary).            | `tests/daily-plan.test.js`             |
| `src/vocabulary-unlock-plan.js` | Staged skill opening (поэтапное разблокирование навыков по дням).                | `tests/vocabulary-unlock-plan.test.js` |
| `src/backup-manager.js`         | Экспорт и импорт состояния с валидацией версий и очисткой чувствительных полей.  | `tests/backup-manager.test.js`         |
| `src/sw-update-manager.js`      | Управление регистрацией, жизненным циклом и обновлением Service Worker.          | `tests/sw-helpers.test.js`             |

### `state/` — Состояние приложения

- `state/store.js`: Централизованный Store. Содержит текущую версию схемы данных (`CURRENT_VERSION = 13`), функции записи `setState`, паттерн подписки `subscribe` и пайплайн миграций со старых версий (v1–v13).

### `ui/` — Компоненты пользовательского интерфейса

Каждый файл отвечает за рендеринг конкретного экрана/маршрута:

- `ui/home.js`: Главный экран (Дашборд, ежедневный прогресс, быстрый старт).
- `ui/plan.js`: Экран детального учебного плана Genki.
- `ui/chapter.js`: Просмотр главы учебника, лексики и грамматики.
- `ui/dictionary.js`: Интерактивный поиск слов и кандзи.
- `ui/statistics.js`: Аналитическая панель (графики удерживаемости, lapses, прогнозы).
- `ui/flashcards/`: Модуль прохождения сессии карточек, рендереры различных режимов (`card-modes.js`, `drawing-mode.js`, `review-fsrs.js`).

### `public/data/` — Обучающий контент

- `content-index.json`: Манифест со списком всех доступных глав и метаданными.
- `lessons/`: Уроки с лексикой, грамматикой и примерами.
- `grammar-quizzes/`: Интерактивные грамматические тесты.
- `particles-dictionary.json`: База данных частиц японского языка.

---

## 🚫 Правила зависимостей между слоями

1. **Модули `src/` не должны импортировать DOM или UI-компоненты из `ui/`**.
2. **`state/store.js` является единственным источником глобального состояния**. Прямая произвольная мутация объектов вне store запрещена.
3. **UI-компоненты читают данные через селекторы store и dispatch'ат доменные команды (`src/domain-commands.js`)**.
