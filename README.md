# 🦊 Kitsune Genki

> Локальный PWA-тренажёр для изучения японского языка по материалам, организованным вокруг структуры Genki I.

> [!WARNING]
> Проект находится в **alpha-версии**. Возможны ошибки, незавершённые функции, несовместимые изменения состояния и сбросы прогресса. Перед обновлением рекомендуется создавать резервную копию данных.

## О проекте

**Kitsune Genki** — неофициальное веб-приложение для изучения японского языка. Оно объединяет учебные главы, интервальные повторения FSRS, практику чтения и письма, план обучения, интерактивные истории и дополнительные мини-игры.

Приложение работает локально в браузере и хранит прогресс пользователя на устройстве. Его можно установить как PWA и использовать без отдельного сервера. Большая часть учебного контента доступна офлайн после загрузки и кэширования.

AI-функции требуют подключения к интернету и пользовательского API-ключа OpenRouter.

## Возможности

### 📚 Учебные главы

В приложение включены 12 глав, организованных вокруг структуры Genki I.

Каждая глава может содержать:

- лексику;
- грамматику;
- диалоги;
- аудирование;
- чтение;
- контрольный список прохождения;
- связанную интерактивную историю.

Главы загружаются по мере необходимости, а не включаются целиком в стартовый JavaScript-бандл.

Пользователь может:

- начинать главы внутри приложения;
- отмечать ранее изученные главы;
- продолжать последнюю активную главу;
- строить план обучения с учётом уже знакомого материала.

### 🎴 FSRS и интервальные повторения

Расписание повторений построено на `ts-fsrs` 5.4.1 и FSRS 6.0.

Приложение разделяет три понятия:

- **расписание** — когда конкретную карточку нужно повторить;
- **mastery** — насколько глубоко пользователь освоил материал;
- **readiness** — насколько материал готов к воспроизведению сейчас.

Для одного слова могут существовать отдельные skill-карточки:

| Навык                | Пример проверки                               |
| -------------------- | --------------------------------------------- |
| `recognition`        | Узнать слово или выбрать значение             |
| `recall`             | Ввести японское слово по русскому переводу    |
| `reading-writing`    | Воспроизвести написание кандзи                |
| `context-production` | Самостоятельно использовать слово в контексте |

Дополнительно реализованы:

- внутрисессионное доучивание после ошибки;
- отдельные оценки Again, Hard, Good и Easy;
- лимиты на введение новых слов;
- практика без изменения расписания;
- отмена последних повторений;
- журнал событий повторения;
- защита от повторной записи одного события;
- миграции старого состояния.

Мини-игры не должны считаться полноценными FSRS-повторениями и не должны изменять расписание карточек.

### ✍️ Режимы практики

В проекте используются разные способы проверки знаний:

- multiple choice;
- ввод японского слова;
- контекстный выбор;
- активный ввод в контексте;
- рисование кандзи;
- задания на частицы;
- сборка предложений.

Сравнение ввода учитывает японскую письменность. Хирагана и катакана могут нормализоваться при проверке там, где это допустимо для конкретного задания.

### 📅 План обучения

План обучения позволяет:

- указать учебную нагрузку;
- выбрать срок;
- отметить ранее изученные главы;
- распределить материал по дням;
- просматривать план как таймлайн или календарь;
- пересчитывать, приостанавливать и изменять план.

Главы, изученные вне приложения, хранятся отдельно от глав, фактически завершённых внутри Kitsune Genki.

### 📖 Истории

В библиотеке находятся истории, связанные с учебными главами.

Они используются для практики:

- чтения;
- лексики;
- грамматических конструкций;
- понимания предложений в контексте.

### 🤖 AI Sensei

Приложение может обращаться к моделям через OpenRouter.

AI-функции включают:

- ответы на вопросы о японском языке;
- объяснение грамматики;
- генерацию учебных историй;
- использование слабых слов пользователя в истории.

Для работы требуется собственный API-ключ OpenRouter.

> [!CAUTION]
> Ответы языковой модели могут содержать фактические, грамматические или переводческие ошибки. AI-материалы следует воспринимать как дополнительную практику, а не как гарантированно правильный учебный источник.

### 🎮 Мини-игры

#### Кроссворд

Пользователь заполняет японские слова по русским подсказкам.

Режим поддерживает:

- выбор между обычным режимом («Все слова») и режимом **«Слабые слова»**;
- хирагану;
- отображение катаканы;
- пересечения слов;
- подсказки;
- озвучивание;
- игровые награды;
- независимую ротацию недавно использованных слов для каждого режима.

#### Охота на слова

Пользователь ищет японские слова в сетке каны по русским переводам.

Поддерживает:

- переключатель режимов: обычный («Все слова») и **«Слабые слова»**;
- уровни сложности (лёгкий, средний, сложный) с проверкой минимального количества слабых слов;
- разные размеры сетки;
- управление мышью, пальцем и стилусом;
- индивидуальные цвета найденных слов;
- подсказки;
- независимую ротацию недавно использованных слов для каждого режима.

> [!NOTE]
> Режим **«Слабые слова»** отбирает только те слова, по которым у пользователя есть реальные признаки затруднений (lapses, Relearning, недавние ошибки Again/Hard, низкая точность или низкая стабильность). Слова без истории повторений в режим не попадают. Результаты мини-игр не изменяют FSRS-карточки и SRS mastery.

### 🔥 Прогресс и геймификация

В приложении присутствуют:

- ежедневный стрик;
- XP;
- уровни;
- монеты;
- достижения;
- ежедневные квесты;
- аватары;
- темы;
- титулы;
- магазин косметических элементов.

Геймификация существует отдельно от FSRS-расписания и не должна подменять реальные доказательства знания материала.

### 💾 Локальное хранение

Основное состояние сохраняется в IndexedDB.

База содержит отдельные хранилища для:

- состояния приложения;
- кэша учебного контента;
- пользовательских UI-настроек;
- журнала FSRS-повторений.

При обновлении приложения выполняются версионированные миграции состояния.

Также предусмотрены:

- полный экспорт прогресса;
- импорт резервной копии;
- перенос старого состояния из `localStorage`.

> [!IMPORTANT]
> Очистка данных браузера может удалить весь прогресс. Используйте экспорт перед переустановкой браузера, очисткой хранилища или тестированием несовместимых изменений.

## Конфиденциальность

У проекта нет собственного пользовательского backend.

По умолчанию прогресс хранится только на текущем устройстве в IndexedDB.

API-ключ OpenRouter:

- хранится локально в состоянии приложения;
- отправляется в OpenRouter при использовании AI-функций;
- может попасть в полный файл резервной копии.

Не публикуйте резервные копии, содержащие рабочий платный API-ключ.

Между устройствами нет автоматической облачной синхронизации.

## PWA и офлайн-режим

Проект содержит:

- Web App Manifest;
- Service Worker;
- отдельную страницу для офлайн-состояния;
- кэш оболочки приложения;
- отложенное кэширование глав и историй.

После первого открытия соответствующего контента приложение может использовать его без сети.

Интернет всё ещё требуется для:

- AI Sensei;
- AI-историй;
- OpenRouter;
- ресурсов, которые не были закэшированы заранее.

Установка PWA доступна в браузерах с поддержкой Progressive Web Apps при работе через HTTPS или `localhost`.

## Локальный запуск

### Требования

Потребуются:

- актуальная LTS-версия Node.js;
- npm;
- современный браузер с поддержкой ES Modules и IndexedDB.

### Установка

```bash
git clone https://github.com/mootxed/Kitsune-GENKI.git
cd Kitsune-GENKI
npm install
```

### Запуск режима разработки

```bash
npm run dev
```

По умолчанию Vite запускается на:

```text
http://localhost:3000
```

Не открывайте `index.html` напрямую через `file://`: загрузка ES Modules, JSON-контента и Service Worker требует локального HTTP-сервера.

## Production-сборка

```bash
npm run build
```

Перед основной сборкой автоматически создаются данные для отрисовки кандзи.

Результат записывается в:

```text
dist/
```

Локальная проверка production-сборки:

```bash
npm run preview
```

### GitHub Pages

Текущая конфигурация Vite рассчитана на публикацию по пути:

```text
/Kitsune-GENKI/
```

При публикации на другом домене или в корне сайта необходимо согласованно изменить:

- `base` в `vite.config.js`;
- `start_url` в PWA-манифесте;
- `scope` в PWA-манифесте;
- пути, используемые Service Worker.

```bash

```

Новые изменения учебной логики должны сопровождаться тестами, особенно если они затрагивают:

- FSRS;

## Известные ограничения

- Проект находится в alpha-версии.
- Некоторые экраны и мини-игры всё ещё активно перерабатываются.
- Облачной синхронизации нет.
- AI-функции требуют API-ключ OpenRouter и подключения к сети.
- AI-ответы не гарантируют идеальную грамматику.
- Локальные уведомления зависят от ограничений браузера и могут не сработать после полного закрытия PWA.
- Офлайн-доступ возможен только для уже загруженных или заранее закэшированных ресурсов.
- Изменения схемы состояния во время alpha-разработки могут потребовать миграций.
- Учебное приложение не заменяет оригинальный учебник, преподавателя и проверенные справочные материалы.
