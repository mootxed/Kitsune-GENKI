# Public License Copies — KotoKitsu

This directory contains full legal texts and attribution notices for third-party software libraries and datasets physically bundled in production builds of KotoKitsu.

## Directory Structure

- `CC0-1.0.txt`: Full text of Creative Commons CC0 1.0 Universal license (Vector Ranks by RhosGFX).
- `hanzi-writer/`: MIT License and attribution notices for the `hanzi-writer` JS library.
- `hanzi-writer-data-jp/`: Upstream licenses (LGPL v3, Arphic Public License, Unicode, SIL OFL) for kanji stroke order data.

Files in this directory are validated and copied during prebuild by `scripts/copy-third-party-licenses.js`.
